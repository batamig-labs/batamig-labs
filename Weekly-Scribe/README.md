# The Weekly Scribe: image prompts

Image prompts for [The Weekly Scribe](https://bengold543022.substack.com/), Ben Gold's Substack. Each week Ben retells the Torah portion as if Genesis happened in the last days of the Kingdom of Judah, the Babylonian exile, and the Return to Zion. I make the images: Claude writes the prompts, and I paste them into ChatGPT.

## How I use it

1. Paste a new post into the Claude Project and approve the shot plan. Claude writes the prompts and commits a new post folder and a new row in the table above.
2. Start a new ChatGPT chat for the post, and paste the prompts in order in that one chat.
3. Save each image in the post's folder, next to its prompts, named after its prompt: `01-header.png`, `02-inline.png`, `03-inline.png`.

## The series look

Each post rotates through one of four modes, so no two weeks look alike:

- **Pastel portrait**: soft pastel in the spirit of Abel Pann's Jerusalem biblical art, for intimate moments.
- **Glazed-brick relief**: like the Ishtar Gate and Persian friezes, for empire and ceremony.
- **Epic painted scene**: Romantic-era oil, for journeys, war, and exile.
- **Illuminated manuscript**: jewel tones and gold leaf, for reflective posts.

Every image includes women, a touch of Phoenician purple, period-accurate detail, rich color, a 16:9 frame, and no text.
